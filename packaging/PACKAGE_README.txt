希沃白板 5 —— 随机启动图（开箱即用包）
=====================================

怎么用（推荐流程）
------------------
  1. 把整个文件夹解压到任意位置（例如 D:\Tools\ 或桌面）；
  2. 双击 安装快捷方式.cmd
       * 自动申请管理员权限（本机 UAC 为"不提示直接提升"时无任何弹窗）；
       * 自动定位本机希沃白板的安装目录与最新版本；
       * 把"希沃白板 5"快捷方式装到桌面、开始菜单和任务栏，图标与希沃白板原版一致；
       * 同时把包内附带的 希沃白板 5.lnk 修正为当前实际路径。
  3. 以后点桌面 / 任务栏的"希沃白板 5"即可，每次都会随机换一张启动图。

关于包内附带的 希沃白板 5.lnk
-----------------------------
Windows 快捷方式内部记录的是"绝对路径"，无法在没运行任何程序的情况下自动适配
任意解压位置，所以随包附带的快捷方式需要先由 安装快捷方式.cmd 修正一次
（第 2 步会顺手完成）。修正后这个 .lnk 也可以直接拖到任务栏固定。

使用前提
--------
* 本机需已安装希沃白板 5（EasiNote5）。
* 程序会自动在本机找"最新版本"的 Main\Resources\Startup 文件夹：
  先读注册表 HKLM\SOFTWARE\WOW6432Node\Seewo\EasiNote5 的 path / VersionPath，
  再退回 %ProgramFiles(x86)%\Seewo\EasiNote5，并按版本号取最高的 EasiNote5_x.y.z.w，
  不需要手动指定版本号，升级白板后也不用改。
* 启动图在 Program Files 下，写入需要管理员权限：程序平时以普通权限运行，
  只在写入被拒绝时自动提权，提权子进程无窗口，全程没有任何弹窗。
* 覆盖成功（SHA-256 校验一致）后才启动希沃白板；失败则不启动，只写日志。

换图
----
把喜欢的图片放进 SeewoStartup 下的任意子文件夹（一个游戏一个文件夹即可），
程序每次运行都会随机挑一个子文件夹、再随机挑其中一张图片覆盖启动图。

移动过文件夹怎么办
------------------
快捷方式记录的是绝对路径，如果把整个文件夹移到了别处，重新双击一次
安装快捷方式.cmd 即可（会重新指向新位置）。

目录结构
--------
SeewoStartup\          图片库（每个子文件夹放一张或多张图）
dist\                  编译好的主程序
scripts\               构建、安装、还原、打包脚本
src\ resources\ docs\  源码与文档
希沃白板 5.lnk         随包附带的快捷方式（安装后即可用）
安装快捷方式.cmd       安装 / 重建桌面、开始菜单、任务栏快捷方式
还原快捷方式.cmd       还原成希沃白板原版快捷方式
使用说明.txt           本文件

日志
----
%LOCALAPPDATA%\SeewoRandomStartup\launcher.log
