# 常见问题

## 双击后什么都没发生？

先看日志 `%LOCALAPPDATA%\SeewoRandomStartup\launcher.log`。程序刻意不弹任何提示框，
失败原因都写在日志里。常见原因：

- 找不到图片库：确认 `SeewoStartup` 目录存在且里面有图片；
- 找不到启动图目录：确认本机已安装希沃白板 5；
- 覆盖被拒绝：日志里应有 `retrying copy with administrator rights`，若紧接着是失败，检查当前账号是否是管理员。

## 会不会每次都要点 UAC？

取决于系统设置。`用户账户控制: 管理员批准模式中管理员的提升提示行为`
设为"不提示直接提升"时全程无窗口；设为"始终提示"时会弹出一次系统 UAC 确认框。

## 希沃白板升级后要改什么？

什么都不用改。程序每次运行都会重新枚举 `EasiNote5_*` 并按版本号取最高。

## 可以放多少张图？

不限。程序先随机挑一个子文件夹，再随机挑该文件夹里的一张图，
所以每个子文件夹被选中的概率相同。

## 图片库可以放别处吗？

可以。在程序目录放一个 `library.txt`，内容写图片库的绝对路径即可。

## 任务栏图标点不动 / 快捷方式失效？

快捷方式记录绝对路径，移动过文件夹后重新运行一次 `scripts/install-shortcut.ps1`
（或包内 `安装快捷方式.cmd`）即可。

## 会常驻后台吗？

不会。程序复制完校验通过后启动白板，然后自己退出，没有服务、没有开机自启。
